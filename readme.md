Учебный проект: каталог книг с CRUD на C# ASP.NET Core MVC, EF Core, LINQ и MS SQL Server.

- 3 таблицы: Books, Authors, Genres со связями один-ко-многим
- CRUD для всех трёх сущностей
- Поиск и фильтр книг, подсчёт книг у автора и жанра через LINQ
- Валидация, начальные данные, защита от удаления связанных записей
